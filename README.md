# Back-End-Development-Songs

This repository contains backend development exercises and API implementations for managing song data. The project demonstrates CRUD operations, API testing, and backend service development using Python and Flask.

## Features

- Get all songs
- Get song by ID
- Add new song
- Update song data
- Delete song
- REST API implementation
- Pytest testing

## Technologies Used

- Python
- Flask
- Pytest
- GitHub
- Docker
